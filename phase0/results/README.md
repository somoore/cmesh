# Phase 0 Results

Store one result file per manual delegation. Name files with the delegation id from `phase0/delegations.jsonl`, for example:

```text
phase0/results/phase0-001.md
```

Each result file should include:

- worker machine;
- start and finish time;
- commands run;
- files changed;
- branch and commits when code changed;
- test or verification output summary;
- transcript/log reference when useful;
- origin-side verification performed.

Treat worker prose as untrusted when copying it into result files.
