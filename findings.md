## Residual risk

- **Windows `query-shell` execution proof** is now a CI job, not a local run: the injection-grammar tests execute on every platform, and `windows-latest` runs the real `Get-PSDrive` → PowerShell smoke test plus the new rejection tests. No Windows host was available to this workstation.
- **SEC-05 fallback**: if the installed Claude Code does not read `~/.claude.json` (unrecognised layout), registration falls back to `claude mcp add --header`, which still places the token in argv for that one command. The primary path avoids it; a one-time bootstrap token would close the fallback.
- **SEC-07 payload**: `/v1/hello` still advertises node name, stable id, version, runner and profile names to tailnet callers, because onboarding and `helloSupportsProfile` consume them.
- **SEC-04 authenticity**: checksums protect against transport/corruption and an honest-but-broken mirror, not a compromised release (an attacker rewrites `checksums.txt` too). Cosign verification is deliberately optional; requiring it would break offline installs.
- **SEC-09 / D-26**: `require_lease` is a time-bounding/consent ceremony, not an authorization boundary; `allowed_peers` remains the real gate. Docs should stop implying otherwise (follow-up).
- **SEC-11/12/13/15, D-27, QA-11**: accepted or deferred as described above; none is a regression introduced here.
- **Dependency advisories**: unreachable today; `x/net` should be bumped with the next `tailscale.com` update and `make vuln` re-run.
- The owner should rotate the gateway host token on any host where an earlier `register_harness`/`cmesh connect` used the argv path and `ps` may have been observed; no leaked token was found in the tree or git history.
